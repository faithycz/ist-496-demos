# Tesla Model Y vs. Ford Mustang Mach-E for a 100-Car Sales Fleet

## Quick comparison

| Criterion | Tesla Model Y | Ford Mustang Mach-E |
|---|---|---|
| Approx. starting price | ~$45k–$55k | ~$38k–$40k |
| EPA range | ~260–330+ miles | ~240–320 miles |
| Seating | 5 seats, optional 7-seat on some versions | 5 seats |
| Cargo | Strong: ~30 cu ft behind rear seats, ~72–75 cu ft max | Solid: ~29 cu ft behind rear seats, ~59 cu ft max |
| Charging | NACS/Tesla Supercharger access | DC fast charging; BlueOval Charge Network |
| Fleet support | Tesla service model, fewer traditional dealers | Broad dealer/service network |

## Fleet takeaways

**Tesla Model Y** is the stronger all-around EV for high-utilization sales fleets. It offers better overall range, excellent charging convenience through Tesla’s Supercharger network, and more cargo room for day-to-day field use. That combination should reduce downtime and improve driver flexibility.

**Ford Mustang Mach-E** is attractive on upfront cost and benefits from Ford’s dealer/service footprint, which can be helpful for a 100-car fleet spread across multiple locations. It is still a capable EV crossover, but it gives up some range and cargo capacity versus the Model Y.

## Recommendation

**Choose the Tesla Model Y** if the priority is maximum driver efficiency, charging ease, and range for a busy sales fleet. **Choose the Ford Mustang Mach-E** only if lower purchase price and established dealer servicing outweigh the Model Y’s operational advantages.
