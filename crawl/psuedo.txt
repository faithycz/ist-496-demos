all imports go here

define page URL
define folder where all markdown files will be saved

function crawl_page(page, page_url):

    print the URL being crawled

    open the page from the URL
    wait for the page to finish loading before continuing

    get the page HTML

    parse the page HTML with BeautifulSoup

    convert the HTML into markdown

    find the first markdown heading (#) in the page

    if a first heading exists:
        keep everything starting from that #

    get the sys_kb_id from the URL

    create the markdown folder if it doesn't exist already

    create the markdown file using the respective sys_kb_id as the filename
    save the markdown content to the file

    print that the file was saved for confirmation

function get_links(page):
    get the page HTML
    parse the HTML with BeautifulSoup

    find all links that point to articles on the page

    convert the links into full URLs and return the list of URLs

function main:
    create a random user agent to access the page

    start playwright
    launch the browser

    create a browser context using the random user agent to operate independent browser session
    
    create a new page

    open the page URL
    wait for the page to finish loading

    get all article links from the main page using get_links

    print the number of links found

    for each article link in the list links:

        generate a random wait time between 1 and 3 seconds using randint

        print the wait time generated
        wait that amount of time between each crawl

        crawl the article page using crawl_page
        save its content as a markdown file

    close the browser context
    close the browser
